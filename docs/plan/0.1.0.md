# 0.1.0

## Main objective

Deliver the first usable release, with public curriculum access and curriculum
modification restricted to an administrator account.

## Features

- Proposal-based curriculum modification for administrators, covering units,
  dependencies, content and recognitions while preserving durable identities
  and history.
- Immediate acceptance of administrator-published proposals.
- Public graph browsing, search, navigation and unit content access.
- Account registration, sign-in and recovery.
- Personal learning paths and unit completion tracking.
