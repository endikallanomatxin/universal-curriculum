# 0.1.0

Initial usable release, with public curriculum access and editing restricted to
an administrator account.

- Administrator-only curriculum modification.

  Publish proposals with units, dependencies, content and knowledge transfers,
  preserving durable identities and history.

  Publishing an administrator proposal accepts it immediately.

- Browse, search and navigate the graph, and read unit content without an
  account.

- Register, sign in and recover account access.

- Create personal learning paths and track completed units.
