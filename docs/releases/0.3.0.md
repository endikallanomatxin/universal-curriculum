# 0.3.0

## Main objective

Open curriculum development to selected contributors while keeping proposal
acceptance subject to manual administrator approval.

## Features

- Added contributor access managed through single-use, expiring administrator
  invitations, while public registration continues to create regular members.
- Added user administration with contributor status, active invitations and
  each user's proposal history.
- Allowed contributors to create private drafts and submit immutable active
  proposals for shared review.
- Added administrator acceptance and rejection without deleting rejected work,
  preserving it as a reference for its authors and administrators.
- Reused the curriculum modification workspace for read-only proposal review,
  including proposal and unit diffs, with administrator decision actions.
- Exposed the contributor submission and administrator decision workflow
  consistently through web, REST and MCP.
