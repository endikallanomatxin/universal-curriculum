# 0.2.0

## Main objective

Provide experimental REST and MCP interfaces for agent clients to interact with
every platform capability delivered in 0.1.0.

## Features

- An OpenAPI contract for an experimental, unversioned `/api` surface. The API
  may change between 0.x releases; a stable versioned path is deferred until
  the compatibility policy is known.
- Consistent JSON resources, errors, strict request validation and pagination
  for growing collections.
- Personal bearer tokens that inherit their owner's permissions, are shown
  once, and are stored only as cryptographic hashes.
- Public reads for the current published curriculum, units, dependencies and
  accepted proposal history.
- Private learning-path and recommendation operations, plus progress reporting
  with `direct`, `recognized` and `completed` states.
- Administrator proposal editing, conflict resolution and publication through
  the same services used by the web interface.
- An agent-oriented MCP server with resources, structured tools and guidance
  for curriculum discovery, learning workflows and administrator proposals.
- OAuth 2.1 authorization-code support with PKCE and Client ID Metadata
  Documents, allowing remote agent clients to connect to a user's account.
