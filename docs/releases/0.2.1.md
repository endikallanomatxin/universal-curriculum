# 0.2.1

## Main objective

Make draft proposals represent their final proposed state rather than the
editing history of units created within the same draft.

## Changes

- Updating a unit created by the same proposal now updates its existing
  `create_unit` change while preserving the unit identity.
- Repeated REST API, MCP and web edits converge to one creation containing the
  final name and content.
- Updates to published units continue to use explicit rename and content
  changes.
