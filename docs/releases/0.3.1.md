# 0.3.1

## Main objective

Help curriculum contributors and agents produce complete, reusable learning
units with coherent prerequisite boundaries.

## Changes

- Established a canonical editorial contract for learner-facing unit content,
  including sufficient intuition, formalism and worked examples where needed.
- Clarified how to factor shared knowledge into focused units without
  duplication, partial overlap or hidden prerequisites.
- Exposed the same canonical authoring documents through MCP resources and the
  argument-free `get_authoring_guidance` tool, so agents can load them even
  when their host does not provide resource reads.
- Directed MCP agents to load that guidance before authoring, search for
  existing knowledge and preserve the same expectations in unit creation,
  editing and dependency tools.
