# 0.2.3

## Main objective

Improve multi-pane layout consistency and reduce production runtime overhead.

## Changes

- Coordinated horizontal padding across visible content panes while preserving
  fixed navigation and structural pane widths.
- Treated declared content modes as usable inner widths and aligned bounded
  lists and forms with their actual readable measures.
- Allocated surplus proposal workspace width to the dense proposal view instead
  of the bounded unit reader.
- Kept narrow unit titles readable by moving completion actions onto their own
  row when necessary.
- Replaced aggregate proposal change totals with compact counts by change type.
- Reused immutable normal and administrator MCP server instances while keeping
  authentication and user identity request-scoped.
- Set Render's Go runtime memory limit to 400 MiB.
