# 0.2.4

## Main objective

Make graph navigation and unit content controls clearer in narrow layouts.

## Changes

- Restored ordinary graph and search navigation after closing a unit's content
  reader, while retaining quick content switching while the reader is open.
- Aligned the unit completion action naturally below narrow titles and removed
  unnecessary button padding.
- Reduced graph title weight and line height, with slightly smaller text,
  spacing and nodes when the graph's own container is narrow.
