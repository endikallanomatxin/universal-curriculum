# 0.2.2

## Main objective

Make curriculum guidance available to people and agents while improving the
responsiveness of large proposal graphs.

## Changes

- Added concise About documentation backed by one canonical Markdown source
  shared with MCP resources.
- Made Markdown, LaTeX and final-state proposal semantics directly discoverable
  from the relevant MCP tools.
- Improved Documentation panel layout and navigation continuity.
- Reduced curriculum layout search from 512 to 128 candidates.
- Reused SVG path samples and skipped geometrically impossible collision checks
  without changing graph routing criteria.
- Reorganized implementation packages under the four top-level backend layers.
