# 0.2.5

## Main objective

Make proposal review and pane navigation more predictable.

## Changes

- Made pane breadcrumbs converge on canonical server-rendered state, preserved
  proposal navigation position and constrained long breadcrumb labels.
- Made published proposal details accessible from history, ordered history and
  rebase timelines newest-first, and added incremental history loading.
- Made content diffs treat rewritten paragraphs as complete replacements while
  retaining word-level detail for small edits.
- Clarified the draft list and the distinction between publishing and accepting
  a proposal, with small visual refinements to proposal changes.
