Agents and other clients can inspect and modify Universal Curriculum through MCP and the HTTP API. Both use the same application workflows and domain rules as the web interface.

Canonical documentation remains available through MCP resources. Before designing or modifying curriculum, agents can load the required authoring documents together with `get_authoring_guidance`, including when their host does not expose resource reads.

Use the relevant tools or API operations for authenticated changes; curriculum changes are prepared in proposals before publication.
