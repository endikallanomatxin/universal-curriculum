A proposal describes the desired semantic change to the published curriculum, not the sequence of edits used to prepare it.

Write proposal titles and rationales in English, matching the canonical
curriculum source. This does not apply to future translation contributions,
which remain linked to that English source.

Draft changes therefore converge on the proposed final state. Updating a unit created in the same proposal updates that creation directly; it does not add rename or content-update history. Changes to an already published unit remain explicit changes against the published state.
